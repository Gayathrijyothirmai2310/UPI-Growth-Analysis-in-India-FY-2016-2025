UPI Growth Analysis in India (FY 2016–2025)

A Power BI dashboard analysing the growth of Unified Payments Interface (UPI) transactions in India from FY 2016 to FY 2025. 
This project explores transaction volume, transaction value, year-over-year growth, average transaction value, festive-season trends, and the impact of COVID-19 on digital payments.
